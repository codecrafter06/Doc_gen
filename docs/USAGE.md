## API Reference

### POST /api/analyze

Analyzes a project and generates documentation.

**Request Body (FormData):**
- `type`: 'github' | 'zip' | 'openapi'
- `url`: string (for GitHub)
- `file`: File (for ZIP/OpenAPI)

**Response:**
```json
{
  "id": "1234567890",
  "markdown": "# Documentation..."
}
```

### GET /api/generate

Downloads generated documentation.

**Query Parameters:**
- `id`: string (documentation ID)
- `format`: 'md' (default)

**Response:**
- Content-Type: text/markdown
- Content-Disposition: attachment

## Programmatic Usage

```typescript
import { RepositoryAnalyzer } from '@/lib/analyzers/repository-analyzer';
import { DocumentationComposer } from '@/lib/analyzers/documentation-composer';
import { generateDocumentation } from '@/lib/gemini';

// Analyze repository
const analyzer = new RepositoryAnalyzer();
const structure = await analyzer.analyzeGithub('https://github.com/user/repo');

// Generate AI-enhanced docs
const aiAnalysis = await generateDocumentation(structure);

// Compose final markdown
const composer = new DocumentationComposer();
const markdown = composer.compose(structure, [], aiAnalysis);

console.log(markdown);
```

## Error Handling

```typescript
try {
  const response = await fetch('/api/analyze', {
    method: 'POST',
    body: formData
  });
  
  if (!response.ok) {
    const error = await response.json();
    console.error('Analysis failed:', error.message);
  }
} catch (error) {
  console.error('Network error:', error);
}
```

## Best Practices

1. **GitHub Repositories**
   - Use public repositories or provide authentication
   - Ensure repository is not too large (< 100MB)

2. **ZIP Files**
   - Keep file size under 50MB
   - Include key files (README, package.json, etc.)

3. **OpenAPI Specs**
   - Use valid JSON or YAML format
   - Include descriptions for better documentation

4. **API Key Management**
   - Never commit `.env.local` to version control
   - Rotate API keys regularly
   - Use environment-specific keys

## Troubleshooting

### "Invalid GitHub URL"
- Ensure URL format: `https://github.com/owner/repo`
- Check repository is public

### "Analysis failed"
- Verify file format is correct
- Check file size limits
- Ensure Gemini API key is valid

### "Documentation not found"
- Documentation IDs expire after session
- Re-run analysis if needed
